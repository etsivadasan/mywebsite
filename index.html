Developer Guide

How To Deploy on GitHub Pages

A quick reference guide for publishing websites, portfolios, and documentation directly from your GitHub repositories.

1

Create Repository

Name your repository username.github.io for your user page or any name for project pages.

git init
2

Add Web Assets

Include an index.html file in the root directory along with CSS, JS, and image assets.

touch index.html
3

Push to GitHub & Enable

Push to your main branch, navigate to Repo Settings → Pages, and select Deploy from a branch.

git push -u origin main
1

Create Workflow Directory

Create a directory path .github/workflows/static.yml in your repository.

mkdir -p .github/workflows
2

Configure Actions Workflow

Use actions/deploy-pages@v4 action to automatically bundle and publish your site artifact on every commit.

uses: actions/deploy-pages@v4
3

Automated SSL Deployment

GitHub automatically provisions free TLS/SSL certificates for your live site within seconds of workflow completion.

https://manav-madhu.github.io
1

Add CNAME Record

In your domain registrar (e.g. Cloudflare, Namecheap), point an ALIGNED / CNAME record to username.github.io.

CNAME @ -> manav-madhu.github.io
2

Create CNAME File

Add a file named CNAME in your repository root containing your exact custom domain name.

echo "yourdomain.com" > CNAME
3

Enforce HTTPS

Check the Enforce HTTPS checkbox in repository Pages settings to ensure encrypted traffic.

Enforce HTTPS: Checked
